# Statistical analysis plan

Analysis choices were written before the project pipeline calculated outcome summaries. This is a retrospective analysis of a public 2008 dataset, not a registered prospective protocol; analyst prior familiarity with the dataset cannot be excluded.

The experimental unit is the assigned customer. All observed assignments remain in their original group. Primary outcome: purchase conversion in the following two weeks. H01: Mens E-Mail minus No E-Mail conversion = 0; H02: Womens E-Mail minus No E-Mail conversion = 0. Two-sided alpha .05; Holm correction across these two tests. Primary decisions use adjusted p-values. Pointwise 95% Newcombe intervals are not family-wise intervals.

Secondary family: direct men's versus women's conversion comparison, three visit comparisons, and three spending comparisons (seven tests, Holm correction). Pooled proportion z tests when expected cells >=5; otherwise Fisher exact. Relative risk intervals use the log method when both event counts are positive; relative lift is undefined at zero reference risk. Spending estimand is mean dollars per assigned customer, including zeros. Welch test of means, with 2,000 empirical bootstrap draws per pair for percentile intervals; seed 20261031. Unique-support multinomial resampling is equivalent to row resampling and limits memory. Bootstrap precision and finite-sample coverage remain limitations for heavy tails.

Overall conversion/visit Pearson tests accompany planned comparisons and do not gate them. No omnibus spending significance claim is made. Baseline diagnostics use pairwise standardized mean differences (pooled sample SD) including one-hot categories; absolute .1 is a descriptive guide, not a randomisation proof. SRM assumes equal marginal assignment probabilities, not fixed exact group sizes. No missingness imputation or duplicate deletion is allowed without investigation.

All eight pretreatment attributes are exploratory segment candidates. History is binned using existing spending groups for interaction analyses. Joint treatment-by-category interactions use OLS with HC3 variance on the additive outcome scale. Seven attributes x two outcomes (conversion/spend) form a 14-test interaction family, Holm adjusted. Segment-specific intervals are pointwise, unadjusted and unsuitable for confirmatory targeting. Sparse groups (<100 assigned or <10 binary events in either arm) are flagged. Significant and non-significant subgroup tests alone do not establish heterogeneity.

Prospective power uses independent-proportion normal approximation (Cohen h), two-sided Bonferroni alpha over groups-minus-one campaign/control comparisons; equal treatment sizes relative to a shared control. Historical MDE is an illustrative design scenario anchored to observed control risk, not observed-effect post hoc power.

Hypothetical decisions use incremental conversion x audience x assumed gross value per conversion x contribution margin, less email and fixed costs. Spending effects are shown separately and never added to conversion value. CI endpoints represent effect uncertainty, not predictive profit quantiles or uncertainty in user assumptions. Transport to a contemporary campaign requires a fresh experiment.
